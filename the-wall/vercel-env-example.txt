# Vercel Environment Variables
# Add these in your Vercel dashboard under Settings > Environment Variables

# Production Environment Variables (WITHOUT VITE_ prefix for Vercel):
SUPABASE_URL=your-supabase-project-url
SUPABASE_ANON_KEY=your-supabase-anon-key

# IMPORTANT NOTES:
# - These are PUBLIC keys that will be bundled into your client-side code
# - This is CORRECT and SAFE for client-side Supabase apps
# - The anon key is protected by Row Level Security (RLS) in Supabase
# - The vite.config.mjs file maps these to VITE_ prefixed variables automatically
# - NEVER add a service role key (it must stay server-side only)

# Instructions:
# 1. Go to your Vercel dashboard
# 2. Select your project
# 3. Go to Settings > Environment Variables
# 4. Add the TWO variables above (without VITE_ prefix)
# 5. Set them for "Production", "Preview", and "Development"
